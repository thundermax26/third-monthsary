# Third Monthsary Gift Site

A three-page romantic GitHub Pages website for R + L.

## Files
- `index.html` — cover + flowers + opening envelope
- `letter.html` — vintage scrollable love letter with autosave
- `memories.html` — scattered photo-memory collage
- `styles.css` — all styling and animations
- `script.js` — navigation, letter autosave, and closing animation
- `assets/flowers/` — decorative flower PNGs
- `assets/memories/` — put your memory photos here

## Memory photo names
Replace/add your photos using these exact filenames:
`memory1.jpg` through `memory9.jpg`.

You can also edit the captions directly in `memories.html`.
